# Support Policy

## Where to Get Help

- **This Project (Docker Image / Packaging / CVEs)**:
  - For questions or ideas regarding container optimizations, open a [GitHub Discussion](https://github.com/lusoris/fileflows-real-image/discussions).
  - For image build errors, driver binding issues, or packaging regressions, open a [GitHub Issue](https://github.com/lusoris/fileflows-real-image/issues).

- **Upstream FileFlows (Application Logic / Features / Node Configurations)**:
  - If you encounter a bug inside FileFlows itself (e.g. flow execution logic, plugin settings, database schemas), please file the issue in the upstream repository:
    `https://github.com/revenz/FileFlows/issues`
  - Community guides and documentation are available at [fileflows.com](https://fileflows.com).

- **Security Vulnerabilities**:
  - Please report security concerns privately using [GitHub Security Advisories](https://github.com/lusoris/fileflows-real-image/security/advisories/new) or by emailing `lusoris@pm.me`.
